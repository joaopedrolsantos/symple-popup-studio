The brand logo — use it for any Seed Supreme lockup instead of typesetting the name.

```jsx
<Logo variant="horizontal" tone="white" height={64} assetBase="../../assets/logo" />
```

Variants: `horizontal` (complete version), `horizontal-reduced`, `vertical`, `symbol` (isologo). Tones: `dark` (Brown #370E00 ink on light) and `white` (knockout on Eerie Black / photography). Keep a safe zone of ½ the symbol width on every side (brand guidelines frame 05); never place the dark lockup on a dark surface. Set `assetBase` to the relative path of `assets/logo` from the page.
